# MainWindow и семейство приборов

## Обзор

`receiver/MainWindow.h/.cpp` — главное окно приложения-приёмника и иерархия самописных приборов на `QPainter`. `MainWindow` собирает дашборд: четыре круглых прибора (высотомер, спидометр, авиагоризонт, компас), два графика истории (`HistoryChart`), группы `QGroupBox` с координатами, батареей и состоянием линии, статистику приёма и CSV-журнал. Классы приборов живут в том же заголовке и наследуют общий базовый `BaseGaugeWidget`.

## Зависимости

Модули Qt: `Widgets` (виджеты, раскладки, `QProgressBar`, `QMessageBox`, `QFileDialog`), `Gui` (`QShortcut`, `QPainter`), `Core` (таймеры, файлы). Проектные типы: `TelemetryPacket` (common), `HistoryChart`, палитра `Theme`.

## MainWindow

### Иерархия и роль

`QWidget` верхнего уровня (не `QMainWindow`): показывается как главное окно, все дочерние виджеты и раскладки — его дети. Родительская цепочка освобождает всё автоматически; единственный явный ресурс — CSV-файл, закрываемый в деструкторе.

### Слоты

#### void onTelemetryReceived(const TelemetryPacket &pkt)

Основной путь данных (queued, из `UdpWorker`). Всегда: обновляет состояние линии (`LIVE`), счётчики статистики и окно pkt/s. Если отображение не на паузе — прогоняет пакет через приборы, графики, подписи и CSV-строку. При паузе значения замораживаются, приём и статистика — нет.

#### void onErrorCountChanged(int count)

Сохраняет суммарное число битых датаграмм и обновляет подпись `Errors:`.

#### void onLinkError(const QString &message)

Неустранимая ошибка (`bind` провалился): показывает `QMessageBox::critical` и завершает цикл событий через `qApp->exit(1)`.

#### void onWatchdogTick()

Тик раз в секунду: проверка потери связи (нет пакетов дольше `kLinkTimeoutMs` = 2000 мс → `LINK LOST`, приборы затемняются), пересчёт статистики, сброс буфера CSV и контроль ошибок записи.

#### void onCsvToggled(bool on)

Включение тумблера: диалог выбора файла, открытие `QFile` (WriteOnly|Truncate), сброс статуса потока (`resetStatus()` — статус `QTextStream` «липкий»), запись заголовка. Отмена диалога возвращает тумблер в выкл. Выключение: флаш и закрытие файла.

### Приватные методы

`updateStatusLabel()` — аннунциатор в группе Link: `PAUSED` (приоритет, warn) / `LIVE` (ok) / `LINK LOST` (crit) / `NO DATA` (dim); цвет + текст, никогда только цвет. `updateLinkState()`, `updateStats()` — см. `onWatchdogTick`. `togglePaused()` — переключение паузы (Space через `QShortcut`).

### Владение, поточность, взаимодействия

Все дочерние виджеты создаются с родителем `this`; файл журнала — член-значение `QFile` + `QTextStream{&m_csvFile}` (порядок объявления гарантирует корректное разрушение). Слоты вызываются только в GUI-потоке (queued-подключения из `UdpWorker` с контекстом `&window`). Внешних соединений окно не порождает — вся проводка в `receiver/main.cpp`.

## BaseGaugeWidget

Абстрактная база приборов. Отвечает за: виртуальную систему координат −100..100 (`setWindow`/`setViewport` — прибор всегда рисуется в квадрате независимо от размеров виджета), тайминг кадров и демпфирование стрелок, оверлей потери данных.

### Защищённые члены для наследников

- `stepTowards(current, target, tau)` — экспоненциальное приближение отображаемого значения к цели; вызывается в `drawGauge()`; пока разница больше `kAnimEpsilon`, база сама планирует следующий кадр (троттлинг ~60 к/с через `QTimer::singleShot`).
- `stepTowardsAngle(current, target, tau)` — вариант для курса с переходом через 360°.
- `drawLinearDial(p, spec, shownValue, caption, unit)` и структура `DialSpec` — общая отрисовка круглого циферблата: подложка, деления с цифровыми метками на мажорных, стрелка, значение с единицей. Используется высотомером и спидометром, устраняя дублирование.
- Именованные константы геометрии: `kTickOuterR = 85`, `kTickMinorR = 80`, `kTickMajorR = 75`, `kLabelR = 63`, `kNeedleLen = 70`, `kNeedleTau = 0.15f`, `kAnimEpsilon = 0.05f`.

### Публичные методы

#### void setStale(bool stale)

Включает/выключает оверлей потери данных: полупрозрачное затемнение и надпись `NO DATA` поверх прибора. Вызывается `MainWindow` при переходах линии `LIVE ⇄ LINK LOST`.

### Защищённые виртуальные методы

#### void drawGauge(QPainter &p) = 0

Чистая виртуальная функция наследников; рисует в виртуальных координатах −100..100, преобразование координат и тайминг уже выполнены базой в `paintEvent`.

## Приборы-наследники

| Класс | Значения | Особенности отрисовки |
|-------|----------|----------------------|
| `AltimeterWidget` | 0..200 м, деления каждые 10, метки каждые 50 | `DialSpec{200, -135°, 270°, 20, 5}`, подпись `ALT` |
| `SpeedometerWidget` | 0..60 м/с, деления каждые 5, метки каждые 15 | `DialSpec{60, -120°, 240°, 12, 3}`, подпись `SPD` |
| `AttitudeWidget` | pitch ±, roll ± | небо/земля с обрезкой, поворот на −roll, лестница тангажа ±10/20° с разрывом в центре, статичный крест самолёта |
| `CompassWidget` | yaw 0..360° | деления каждые 30°, румбы N/E/S/W, демпфирование через `stepTowardsAngle`, нормализация показания в 0..359 |

Сеттеры (`setAltitude`, `setSpeed`, `setPitchRoll`, `setYaw`) сохраняют целевое значение и вызывают `update()`; отображаемое значение каждый кадр приближается к цели с τ = 150 мс — стрелка движется плавно, а не прыгает.

## Пример использования

Прибор как отдельный виджет:

```cpp
auto *altimeter = new AltimeterWidget(parent);
altimeter->setMinimumSize(200, 200);
altimeter->setAltitude(150.5f);   // стрелка пойдёт к значению плавно
altimeter->setStale(true);        // затемнение + NO DATA
```

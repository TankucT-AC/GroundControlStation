# HistoryChart

## Обзор

`receiver/HistoryChart.h/.cpp` — виджет-график истории одного значения за последние 60 секунд (strip-chart). Хранит кольцевой буфер точек «время получения → значение», при каждой вставке отбрасывает устаревшие, при отрисовке сам масштабирует ось Y по диапазону данных. Рисуется обычным `QPainter` в пиксельных координатах (в отличие от приборов с их виртуальной системой −100..100).

## Зависимости

Модули Qt: `Widgets` (`QWidget`, `QPaintEvent`), `Gui` (`QPainter`, `QPainterPath`). Проектный заголовок `Theme.h` — цвета и моноширинный шрифт. Класс не знает ни о протоколе, ни об остальных классах приложения — переиспользуемый строительный блок.

## Публичные методы

#### explicit HistoryChart(const QString &title, const QString &unit, QWidget *parent = nullptr)

Конструктор: заголовок и единица измерения показываются в шапке графика. Устанавливает минимальную высоту 110 px и политику размера Expanding × Minimum.

#### void appendSample(float value)

Добавляет точку с текущим локальным временем, отбрасывает точки старше `kSpanMs` (60 000 мс) и перерисовывает виджет. Вызывается из `MainWindow::onTelemetryReceived` на каждый пакет; на паузе не вызывается — график честно замирает вместе с отображением.

## Защищённые виртуальные методы

#### void paintEvent(QPaintEvent *event) [override]

Полная отрисовка: фон в цвет `Theme::gaugeFace`, область построения с отступами под подписи, три горизонтальные линии сетки с значениями (максимум / середина / минимум), полилиния данных `QPainterPath` цветом `Theme::ok`, маркер последней точки, подписи `60 s ago` / `now` по оси времени, текущее значение справа в шапке. Диапазон Y автоскейлится с 10 % полем; для плоского ряда принудительно расширяется на ±1, чтобы избежать деления на ноль.

## Владение и поточность

Обычный дочерний `QWidget` (родитель из конструктора), внутреннее состояние — `std::deque<Sample>` без динамических владений. Используется только в GUI-потоке.

## Пример использования

```cpp
auto *chart = new HistoryChart("Altitude", "m", this);
chart->appendSample(150.5f); // точка «сейчас»
```

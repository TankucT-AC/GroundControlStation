# main (sender)

## Обзор

`sender/main.cpp` — консольный генератор телеметрии без GUI: по таймеру `QTimer` собирает пакет `TelemetryPacket` с плавно меняющимися синтетическими значениями и отправляет его датаграммом `QUdpSocket`.

## Настройка QCoreApplication

`QCoreApplication` (без GUI), имя и версия — для `--version`.

## Обработка аргументов командной строки

| Опция | По умолчанию | Описание |
|-------|--------------|----------|
| `-p` / `--port` | `12345` | Порт назначения |
| `-a` / `--addr` | `127.0.0.1` | Адрес назначения |
| `-r` / `--rate` | `50` | Интервал отправки, мс |

Все три значения валидируются через `*ok`-параметры преобразований (`toUShort`/`toInt`), адрес — через `QHostAddress::isNull()`); невалидные (включая `rate ≤ 0`, что залило бы линию нуль-интервальным таймером) — stderr и код выхода 1.

## Генерация телеметрии

Лямбда на `QTimer::timeout`: высота — синусоида 100 ± 50 м; скорость — 15 ± 10 м/с; тангаж/крен/курс — синусоиды разных фаз (курс 0..360); GPS — базовая точка 55.751244, 37.618423 с колебанием ±0.01°; батарея — убывание от 100 % с сбросом на 100 при достижении 20 %; спутники — 8..12 (`QRandomGenerator`). Ошибка `writeDatagram` (−1) — `qWarning` и продолжение работы.

## Цикл событий

`timer.start(rateMs)` → `app.exec()`; завершение по сигналу ОС.

## Зависимости

`TelemetryPacket.h` (common); Qt: `QCoreApplication`, `QCommandLineParser`, `QDateTime`, `QRandomGenerator`, `QTimer`, `QUdpSocket`.

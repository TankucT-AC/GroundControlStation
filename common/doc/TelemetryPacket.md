# TelemetryPacket

## Обзор

`common/TelemetryPacket.h/.cpp` — единственный источник истины о бинарном UDP-протоколе проекта. Структура описывает 46-байтовый little-endian пакет телеметрии БПЛА и содержит статические методы сериализации: упаковку полей в буфер, распаковку с валидацией и расчёт контрольной суммы CRC-16/CCITT. Оба приложения (`sender` и `receiver`) и все тесты используют именно эту структуру — смещения полей заданы константами и не дублируются нигде больше.

## Зависимости

Модуль `common` собирается как статическая библиотека и линкуется с `Qt6::Core` (используется только `std::optional` из стандартной библиотеки; зависимость от Qt нужна лишь для сборки в дереве проекта). Заголовок подключается напрямую: `#include "TelemetryPacket.h"` (include-каталог `common/` пробрасывается через `target_include_directories(common PUBLIC ...)`).

## Типы

| Имя | Вид | Описание |
|-----|-----|---------|
| `TelemetryPacket` | `struct` | 46-байтовый пакет телеметрии; поля соответствуют wire-формату |

Поля структуры:

| Поле | Тип | Смещение в пакете | Описание |
|------|-----|-------------------|----------|
| `timestamp` | `uint32_t` | 2 | Метка времени отправителя, unix-ms (uint32 — переполняется каждые ~49,7 суток) |
| `altitude` | `float` | 6 | Высота, м |
| `speed` | `float` | 10 | Скорость, м/с |
| `pitch` | `float` | 14 | Тангаж, градусы |
| `roll` | `float` | 18 | Крен, градусы |
| `yaw` | `float` | 22 | Курс, градусы |
| `latitude` | `double` | 26 | Широта |
| `longitude` | `double` | 34 | Долгота |
| `battery` | `uint8_t` | 42 | Заряд батареи, % |
| `satellites` | `uint8_t` | 43 | Количество спутников |

## Константы

| Имя | Тип / значение | Описание |
|-----|----------------|----------|
| `MAGIC_0` | `uint8_t = 0x55` | Первый байт-маркер пакета |
| `MAGIC_1` | `uint8_t = 0xAA` | Второй байт-маркер пакета |
| `PACKET_SIZE` | `size_t = 46` | Полный размер пакета в байтах |
| `OFFSET_ALTITUDE … OFFSET_CRC` | `size_t` | Смещения полей (6, 10, 14, 18, 22, 26, 34, 42, 43, 44) |

## Функции

#### static uint16_t crc16(const uint8_t *data, size_t len)

Считает CRC-16/CCITT (полином 0x1021, инициализация 0xFFFF). Известный контрольный вектор: для строки `"123456789"` возвращает `0x29B1`, для пустого ввода — `0xFFFF`. Потокобезопасна: чистая функция без состояния.

#### static void pack(uint8_t *buffer, const TelemetryPacket &pkt)

Записывает все поля структуры в `buffer` в формате протокола: магические байты, поля little-endian, в конце — CRC от первых 44 байт. Предусловие: буфер размером не меньше `PACKET_SIZE`; CRC вычисляется по диапазону `[0, PACKET_SIZE - 2)`.

#### static std::optional<TelemetryPacket> unpack(const uint8_t *buffer, size_t len)

Парсит и валидирует буфер. Возвращает заполненную структуру, либо `std::nullopt`, если: длина не равна `PACKET_SIZE` ровно, магические байты не совпадают или CRC не проходит. Валидация размера строгая — «хвост» сверх 46 байтов не допускается (отбраковка датаграмм нестандартного размера выполняется в `UdpWorker` до вызова).

## Пример использования

```cpp
TelemetryPacket pkt;
pkt.altitude = 150.5f;
pkt.speed = 22.3f;

uint8_t buf[TelemetryPacket::PACKET_SIZE];
TelemetryPacket::pack(buf, pkt);

if (auto parsed = TelemetryPacket::unpack(buf, sizeof(buf))) {
    qDebug() << "altitude:" << parsed->altitude;
}
```
